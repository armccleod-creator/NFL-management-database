# NFL Management Database

A relational MySQL database project for managing NFL teams, players, coaches, stadiums, contracts, games, player statistics, and injuries.

## Features

- Tracks all 32 NFL teams and their stadiums
- Stores player, coach, contract, game, injury, and statistic information
- Uses primary keys, foreign keys, and relational table design
- Includes sample data and reporting queries
- Demonstrates joins, aggregates, grouping, ordering, and CASE statements

## Technologies

- MySQL
- SQL

## Run Locally

1. Open MySQL Workbench or a MySQL command-line client.
2. Run `NFLDatabase.sql`.
3. The script creates and selects the `NFLManagements` database, builds its tables, inserts sample data, and runs example queries.

## Included Queries

- Players and their teams
- Player contract salaries
- Player injury status
- Quarterback passing-yard totals and averages
- Game results and winners
- Team-win and quarterback-performance reports

## Note

This is an educational database project. The NFL information is sample data up through the first 6 weeks of the 2025/2026 season
